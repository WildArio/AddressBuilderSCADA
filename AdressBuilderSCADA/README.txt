Что получается. Каждая строка имеет один и тот же формат похоже.

Если взять Node:

#Node(TCP/IP);;Noode1;;;;;;;;

# - начало группы какой-то
Node(TCP/IP) - что за элемент структуры Modbus SCADA
; - Конец параметра
- Пустое место
; - следующий
Noode1-имя
;;;;;;;; - пустые параметры

;$... это всё находится внутри Node, как его параметры. Только если для тега это всё через ; отделено, тут будто как отдельные группы вынесены

И теперь если рассмотреть один из тегов под всеми разделами:

#Tag;;T2;;0;3;1000;18;{318729F3-2A6F-4518-903D-A101068F440B};0;3

# - опять, похоже говорим что новая группа? Или элемент
Tag - что за элемент структуры Modbus SCADA
; - Конец параметра
- пустое место
; - следующий
T2 - имя тега
; - Конец параметра
- Нашёл что это комментарий который можно подписать у чего-то
; - следующий
0 - адрес тега
; - следующий
3 - регион (1 - coils, 2 - Discrete, 3 - holding, 4 - input)
; - следующий
1000 - не понятно что это. Думал что время опроса, но нет, оно не меняется.
; - следующий
18 - тип данных (11 - Bool, 2 - Int16, 17 - UInt16, 3 - Int32, 1000 - Float16, 4 - Float32, 18 - Word, 19 - Dword)
; - следующий
{318729F3-2A6F-4518-903D-A101068F440B} - ID тэга. Похоже программа сама его присваивает. Можно оставить пустым? Не знаю.
;
0 - порядок байт (0 - Default, 1 - BE, 2- LE, 3 - BE_4_3_2_1, 4 - BE_3_4_1_2, 5 - LE_1_2_3_4, LE_2_1_4_3)
;
3 - тип доступа (1 - ReadOnly, 2 - WriteOnly, 3 - ReadAndWrite)
;
